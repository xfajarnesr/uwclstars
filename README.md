# UWCL Stars

Joc de sobres de cromos de la UEFA Women's Champions League 2026/27 per a l'optativa de Matemàtica aplicada de 1r de Batxillerat (INS Manolo Hugué).

L'objectiu és entendre les caixes botí i els sobres de cromos des de les matemàtiques: probabilitat, valor esperat, el problema del col·leccionista i com les regles d'un joc canvien el que costa aconseguir les coses.

- Joc: `index.html`
- Configuració: `js/dades.js`
- Motor d'atzar (no s'ha de tocar en fer versions): `js/motor.js`
- Connexió amb el full de Google: `servidor/INSTRUCCIONS.md`
- Notes de disseny: `DISSENY.md`
- Fitxa de l'alumnat: `docs/UWCL_Stars_fitxa_alumnat.docx`
- Kit per crear el vostre joc: `kit/` (plantilla HTML d'un sol fitxer, full de càlcul i prompt). La plantilla es regenera amb `python3 eines/fes_plantilla.py` i el full amb `python3 eines/fes_full.py`.
- Context per continuar el projecte: `CONTEXT.md`

Joc educatiu sense diners reals. Valors de les jugadores: estimació pròpia.
